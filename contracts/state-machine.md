# 共同状态与数据边界（v2 目标）

## 主状态

| 当前阶段 | 进入下一阶段的条件 | 下一阶段 |
| --- | --- | --- |
| lobby | 两个座位、双方 ready=true；随机身份仅生成一次 | brief |
| brief | 双方先确认本人指令，再完成教学 | map |
| map | 双方确认进入当前 chapter | story |
| story | 双方剧情已读 | event |
| event | 每人一个尝试，均已最终计分和发奖 | invest |
| invest | 双方已确认投入；同事务固定共同结果 | result |
| result | 双方继续；第一地点成功 | chapter=1，map |
| result | 双方继续；第二地点成功 | complete |
| result | 双方继续；当前地点失败 | failed |
| 任一非终态 | 有效主动退出或恢复窗口超时 | ended |

result 产生时设置 outcome：地点失败为 failed，第二地点成功为 complete，第一地点成功为空。结果已固定，即使尚未读完结果也不允许修改尝试或投入。result 的 ended=false 仅保留结果确认操作；complete/failed/ended 为 ended=true 的终态。退出和连接超时分别记录 endReason=player_exit/connection_timeout，不生成新的剧情失败。

第一地点需求 int=5/str=5；第二地点 int=6/str=4。初始每人 int=5/str=5。智力奖励 0/3/6/10；武力奖励为有效命中数0至10。超额投入不退；任一项不足共同失败；只开放两地点。旧地点回看使用 records，不能再次 enter/start。

## 暂停与计时

paused 独立覆盖主阶段。后台主动报告立即暂停，未报告则八秒失联检测。纯方向变化不报告暂停。双方小游戏共同停止有效计时，服务器确认暂停前的时长不回补。pause 包含 id、reason、startedAt、deadlineAt、resumeConfirmed 两座位标记。

暂停期间仅 presence、resume、exit 和读取可用；正在进行的输入拒绝。首次暂停建立120秒窗口，同一批次不会被心跳刷新。双方在线、可见并确认同一 pauseId 后恢复。服务重启按已持久化锚点检查超时并进入暂停，不能假定原玩家仍在线。终态不再因心跳变化暂停。

60秒智力事件；武力沿用现有22200毫秒配置、3000毫秒预备、十机会每2000毫秒开始、每机会1200毫秒有效。所有时长属于固定 rulesVersion。服务端收到 hit 时校验时间，不采信客户端最终命中数；当前不承诺额外延迟补偿，实机若需调整须更新规则版本及契约。区内首次有效点击即消耗该机会，点错不补；区外输入不计命中。超时按已确认输入自动结算。

## 数据范围

| 范围 | 可包含 | 不可包含 |
| --- | --- | --- |
| 公共 | 阶段、双方属性、公开确认、事件类型/完成/奖励、已确认投入、共同结果、连接与暂停 | 双方身份、答案、未提交草稿、凭证 |
| 本人 | 本人尝试、题面选项、已保存答案、剩余时间、本人投入草稿、本人私密指令专用响应 | 对方答案、对方身份、对方凭证 |
| 仅服务端 | 正确答案、身份分配、token摘要、去重参数摘要、内部账本 | 不得整体展开返回 |

本人武力目标序列可用于本地渲染；不能当成对方公共事件返回。个人指令只由专用接口读取，通用教程不包含叛徒后续规则。

## 不变量与验收

1. 两个座位；每人每地点一个尝试、一笔投入；每尝试一个最终奖励；每地点一个共同结果。
2. 当前属性=初始属性+已确认奖励-已确认投入，永不为负。
3. 创建、加入、扣除、发奖、结算在提交后才确认；响应丢失重试不重复执行。
4. 对方身份及凭证不能从任何公共或本人接口获得。
5. 暂停、刷新、重启不重生成身份、题目或目标序列，不重置尝试。
6. endedAt 起公共档案及本人恢复访问保留24小时，之后清理；终态只读，不能恢复玩法。清理覆盖去重及私密数据；未开始邀请独立按有效期处理。
7. 两端提交冲突、乱序输入、旧会话心跳必须有明确结果；不能静默覆盖较新数据。
8. 20房间40客户端测试，PRD指定网络条件下状态变化两秒内可见。测试必须覆盖两台真实手机，不能仅靠模拟请求。
