# 五里亭奖励结算修复

## 问题

线上五里亭交锋在结算时出现 HTTP 409 / DATABASE_23505，客户端可能停留在回合倒计时 0 秒。

服务会在同一次协作尝试中，为每位玩家分别写入智力、武力两条奖励。线上 `anxian.resource_ledger` 的主键仍为 `(room_id, seat, attempt_id)`，使第二条属性奖励违反唯一约束，事务回滚。

## 已执行的修复

经用户同意，2026 年 11 月 18 日在线应用既有迁移 `20261116090000_dual_attribute_rewards`：主键调整为 `(room_id, seat, attempt_id, attribute)`。

- CloudBase 迁移任务：`task-393347602dfa4bc8`，状态 `Succeed`。
- 修复无需重新部署容器；线上 `anxian-backend-020` 保持 100% 流量，服务状态 `normal`。
- 未修改玩家手牌、属性余额或真实奖励记录。

## 验证与恢复

直接查询线上数据库，确认奖励表主键已包含 `attribute`。使用复制实际表结构的临时表验证：同一局两名玩家的四条双属性奖励可写入，相同属性的重复奖励仍触发唯一约束。临时表随事务结束清理。

玩家可刷新原页面恢复同步；此前因数据库冲突回滚的结算可重新尝试。真实玩家对局恢复情况仍待测试人员确认。
