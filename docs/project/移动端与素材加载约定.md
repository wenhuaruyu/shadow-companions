# 移动端与素材加载约定

## 横屏要求

主页面及所有小游戏要求横屏。竖屏时显示全屏“请横屏游玩”模态遮罩，转为横屏自动关闭，保留当前页面与联机进度。旋转设备不会暂停服务端倒计时。

公共入口为 `src/platform/landscape.js` 与 `landscape.css`。主页面和已有小游戏直接引用；构建时也会为后续 `public/games/*.html` 自动补齐引用。浏览器支持时尝试原生横屏锁定；iOS、微信等不允许网页强制旋转的浏览器由遮罩约束。

## 图片交付

原设计的 PNG 保留在 `public/assets/figma`，不用修改剧情稿和原始美术。`npm run build` 使用开发依赖 sharp 生成质量 86、透明度质量 100 的 WebP，产物名包含内容哈希，并同步改写场景、脚本和样式中的资源地址。修改图片后必须重新构建，不能直接覆盖旧的哈希资源。

生产构建目前 60 张 PNG 为 106.0 MiB，交付的 WebP 合计 11.3 MiB，减少 89.4%。首屏背景优先加载；当前页完成后只预取下一页 HTML 和至多两张新图片，节省流量模式下不预取。

哈希 WebP 缓存一年；其他美术和字体缓存一天；HTML、脚本和场景先向服务器校验，避免新版本长期使用旧代码。ETag 命中返回 304。文本的 Brotli/Gzip 在构建时生成；旧页面仍可使用 PNG 地址，由服务端兼容返回对应 WebP。字体使用 font-display: swap。

## 验收

2026-11-14 本地生产构建验收：主入口、第一章智力、第一章武力、第二章协作均通过 390×844 竖屏遮罩与 844×390 横屏恢复检查，浏览器运行异常 0。相同浏览器再次打开首页，图片网络传输为 0 字节。服务端素材测试覆盖 174 个场景、缓存验证及私有文件路径隔离。
