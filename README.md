# 暗线同行者

两台手机横屏游玩的历史题材合作游戏。首周目标为黄慕兰寓所、铜锣湾避风塘两个地点的联网体验。

当前阶段：项目初始化。目录、需求基线与本地启动入口已建立，邀请、加入与同步功能尚待实现。

## 目录

- `apps/web`：可运行前端，后续依据 Figma 高保真原型实现。
- `apps/server`：后端业务服务。
- `contracts`：前后端共同维护的接口契约与样例。
- `docs/project`：第一天工作清单与决策记录。
- `docs/两地联网横屏MVP`：产品需求、流程图与可编辑文档。

## 本地启动

使用支持 ECMAScript 模块的 Node.js 环境。当前工程没有第三方运行依赖。

```sh
npm run dev:server
npm run dev:web
```

前端预览默认位于 `http://localhost:5173`，后端健康检查位于 `http://localhost:3000/health`。

启动入口仅供本地开发；两个真实手机通过邀请进入同一局的能力属于第一天待完成项，不能把当前静态骨架当作已完成的联网体验。

## 已确定的约束

- 横屏地图是主操作入口；转竖屏保留横屏布局，不重新排版、不退出或重置。
- 一人开始生成邀请链接，另一人打开链接加入，两人准备后开始。
- 首期不做账号、匹配、房间列表、聊天或观战。
- 五地点地图只开放前两个地点。
- 两类小游戏获得现有智力或武力；协商投入从现有属性中实际扣除。
- 本人秘密身份只能由本人读取，公共文案不向情报员直接揭示叛徒。
- Figma 原型与实际前端分别交付，前后端通过共同契约联调。

## 工作流

需求与契约先更新，再实现与联调。凭证、环境变量与运行数据不得提交到 Git。首次提交之前先检查 `git diff --cached`。
