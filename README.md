# 暗线同行者

基于 `docs/两地联网横屏MVP/暗线同行者_两地联网横屏MVP_PRD.md` 实现的双人横屏合作网页游戏。

## 启动

需要 Node.js 20 或更新版本，无第三方运行依赖。

```sh
npm start
```

打开 http://localhost:3000 。两台手机接入同一局域网后，通过电脑局域网 IP（如 `http://192.168.1.20:3000`）打开页面。创建行动并将邀请链接交给另一台设备，分别准备即可开始。不要把 localhost 链接分享给手机。服务默认监听 `0.0.0.0`，可使用 PORT、HOST、DATA_DIR 环境变量覆盖。对外部署使用 HTTPS 反向代理。

```sh
npm test
npm run check
```

后端同时提供网页与 API，无需独立启动前端开发服务器。原 `dev:web` 仅提供静态文件，应使用上述统一入口游玩。

## 已实现

- 年代风格营救网络示意地图，五节点、两章开放、完成回看。
- 双人创建、邀请、占座、准备；本人凭证保存在当前浏览器。
- 服务端随机分配私密指令，公共响应排除身份与对方凭证。
- 三页教学、四段开场、双人共同进入与已读确认。
- 两组真实三题谜题，服务端计分为 0、3、6、10。
- 固定十机会反应小游戏，服务端按有效窗口和首触记录计分。
- 协商投入、余额校验、实际扣除、防重复发奖与扣除、共享结算。
- 心跳与后台暂停、120秒恢复期限、本地凭证恢复、文件存档。
- 固定横屏画布，竖屏保留布局并允许横向滚动。

运行存档位于 `apps/server/data/`，含恢复凭证，仅保存在服务器且不应提交。当前为单进程文件存储实现，不支持多实例并发部署。轮询约350毫秒，反应反馈受网络延迟影响，需实机调优。
